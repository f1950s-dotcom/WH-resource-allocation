# 倉庫人員配置最適化システム 設計書
## 第5章 画面設計

---

### 5.1 画面一覧

| 画面ID | 画面名 | 説明 |
|--------|--------|------|
| SCR-001 | ホーム（ダッシュボード） | 日付選択・進捗確認 |
| SCR-010 | 人員マスタ一覧 | 人員の登録・編集・削除 |
| SCR-011 | 人員マスタ詳細 | スキル・勤務条件の設定 |
| SCR-020 | 工程マスタ一覧 | 工程の登録・編集・削除 |
| SCR-021 | 工程接続設定 | 工程チェーンの設定 |
| SCR-030 | 物量変換マスタ | 変換係数の設定 |
| SCR-040 | 条件マスタ | 期限・システム条件の設定 |
| SCR-100 | 物量登録 | 入出庫物量の15分単位入力 |
| SCR-200 | 物量展開 | 展開実行・結果ヒートマップ |
| SCR-300 | 人員配置最適化提案 | 3案の表示・比較・選択 |
| SCR-310 | 配置案詳細 | ガントチャートで詳細確認 |
| SCR-400 | シフト生成 | 人別・工程別シフト表示・Excel出力 |
