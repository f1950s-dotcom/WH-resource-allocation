# 倉庫人員配置最適化システム 設計書
## 第1章 システム概要

---

### 1.1 システム目的

倉庫における入出庫物量の計画値をもとに、工程・時間帯別の最適な人員配置を自動提案するWebアプリケーション。
計画的な配置により、作業完了時間の厳守・人件費の最小化・人員移動の最小化を実現する。

---

### 1.3 ユーザー・利用形態

| 項目 | 内容 |
|------|------|
| 利用形態 | Webアプリ（シングルユーザー） |
| 想定人員規模 | 最大50人程度 |
| 時間粒度 | 15分単位 |
| データ保存 | RDB（SQLite または PostgreSQL） |

---

### 1.4 処理フロー

```
① マスタ登録
   └─ 人員・工程・物量変換係数・条件 を事前設定

② 物量登録（日次）
   └─ 入庫・出庫それぞれの物量を15分単位で入力

③ 物量展開（自動計算）
   └─ 物量登録 × 物量マスタ係数 → 各工程の処理量
   └─ 各工程の処理量 ÷ 工程基準生産性 → 必要人時（15分単位）

④ 人員配置最適化提案
   └─ 条件マスタ・人員マスタをもとに最適化アルゴリズム実行
   └─ 3案提示（最速完了案 / 最低コスト案 / 最小移動案）

⑤ 案の選択 → シフト生成
   └─ 人別シフト（誰がいつどの工程か）
   └─ 工程別シフト（工程ごとに誰がいつ何人いるか）
   └─ Excel出力
```

---

### 1.5 優先順位（最適化の価値基準）

| 優先度 | 評価軸 | 説明 |
|--------|--------|------|
| 1位（最重要） | 作業完了遵守 | 各工程チェーンの終了必須時刻までに完了すること |
| 2位 | 総人件費最小 | 時給 × 作業時間の積み上げ（残業は×1.2） |
| 3位 | 工程移動回数最小 | 同一人員の工程切替回数を減らす |

---

### 1.6 休憩ルール

| ルール | 内容 |
|--------|------|
| 昼休憩 | 11:30〜13:00 の間に60分の昼休憩を配置 |
| 法定休憩 | 6時間超労働で45分以上の休憩を確保（昼休憩で充足する場合は追加なし） |
| 残業定義 | 8時間超の労働時間分（時給×1.2） |
